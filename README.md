## ▶️ How to run the examples

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/java-course.git
cd java-course
```

Compile and run a single file from the command line:

```bash
javac path/to/Main.java
java -cp path/to Main
```

Or simply open the project in your IDE and run the `Main` class of the lesson you want.

For Maven-based projects:

```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="com.example.Main"
```
